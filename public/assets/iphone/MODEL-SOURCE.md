# Sage iPhone 17 frame

iphone-17-sage-front.png is a transparent front render derived from Apple's original iPhone 17 geometry, with the exterior remapped to sage. No app content is baked into this frame.

Original model source, retrieved November 8, 2026:
https://www.apple.com/105/media/us/iphone-17/2025/b2c72de3-1cbc-4e24-b4d3-23c7abcec4ec/ar/iphone-17-e-sim.usdz

The build uses only the static PNG. The 3D viewer, model file, controls and Three.js dependencies were removed at the user's request.
